# 📌 Project 1 – Advanced EDA & Feature Engineering

### Overview
Performed Exploratory Data Analysis (EDA), handled missing values and outliers, and engineered new features to prepare the Titanic dataset for machine learning.

### Dataset
- Titanic Dataset
- 891 rows × 12 columns

### Highlights
- Missing value imputation
- Outlier detection (IQR & Z-Score)
- Feature engineering
- Data visualization
- Clean dataset generation

---

# 📌 Project 2 – Supervised Learning: Fraud Detection Pipeline

### Overview
Developed a machine learning pipeline to detect fraudulent credit card transactions using techniques for highly imbalanced datasets.

### Dataset
- Credit Card Fraud Detection Dataset
- 284,807 transactions

### Highlights
- SMOTE for class balancing
- Logistic Regression
- Random Forest
- GridSearchCV
- Precision, Recall, F1-Score & ROC-AUC evaluation

# 📌 Project 3 – Unsupervised Learning: Customer Segmentation

### Highlights
